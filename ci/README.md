# GitHub dependency pilot

The Java 21 pilot builds each IC4J prerequisite from a pinned Git commit into a
fresh, run-local Maven repository. The Agent's CI Gradle init script limits
`org.ic4j` dependency resolution to that repository. It builds Candid (including
Gson), Agent, Internet Identity, Management, React Native and Spring in that
order. It builds but does not separately test those prerequisite modules here.

Codegen runs its existing `check`, including Java compilation of sources
generated by tests, and builds the packaged CLI. The CLI generates a Java
client from a synthetic local Candid fixture, without requiring an ICP
endpoint. The pilot compiles the client with Java 8 bytecode/API compatibility
against the Agent and Candid artifacts from the same job. The upstream Swift
and RosettaNet execution exclusions remain unchanged.

An explicit `[run codegen pilot]` push to `ci/codegen-source-pilot` validates
the branch before merge. Manual dispatch is available once the workflow is on
the default branch. No packages are published.
